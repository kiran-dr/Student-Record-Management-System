# 🎓 Student Record Management System

A simple Python-based Student Record Management System developed using basic Python concepts.

## Features
- Add Student
- Display All Students
- Search Student
- Update Student
- Delete Student
- Stores records in `students.txt`

## Technologies Used
- Python
- Functions
- Dictionary
- File Handling

## How to Run
1. Open the project in VS Code.
2. Run `main.py`.
3. Select an option from the menu.
